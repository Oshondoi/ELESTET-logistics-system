# Стандарты Excel-экспорта

Все Excel-файлы ELESTET перед записью workbook должны проходить через `applyExcelWorksheetStandards` из `src/lib/excelStandards.ts`.

## Общие правила

- Ширина колонки рассчитывается по заголовку и содержимому; стандартный максимум — 60 символов.
- Товарные баркоды, артикулы WB/продавца, ШК коробов, ID заказов и поставок хранятся как текст, чтобы Excel не менял значение и не включал экспоненциальную запись.
- Количества, цены и даты остаются числовыми/датами там, где формат выгрузки это поддерживает.
- КИЗ `Честного знака` не участвует в автоматическом преобразовании, пока его отдельный формат не утверждён.

## Системный экспорт коробов fulfillment

- Работает на уровнях партии, поставки и отдельного короба.
- Режимы: `По коробам`, `По баркодам`, `Оба`.
- `По баркодам` создаёт одну строку на товарный баркод и суммирует количество по всем включённым коробам.
- `Оба` создаёт один XLSX: первым листом `По баркодам`, вторым — `По коробам`.
- Обязательная идентичность короба в этом режиме — `Системный ШК короба`. Выбранные дополнительные колонки добавляются без изменения основных правил.

## WB-экспорт коробов fulfillment

- Доступен только когда для каждого выбранного короба сохранена полная проверенная пара WB-кодов из Excel-импорта. API package codes источником этого экспорта не являются.
- Режим всегда `По коробам`; `По баркодам` и `Оба` остаются видимыми, но недоступны с подсказкой `Доступно для системных ШК`.
- Дополнительные колонки отключены: результат обязан быть готовым однолистным шаблоном WB ровно из пяти колонок и с точными заголовками:
  1. `Баркод товара`
  2. `Кол-во товаров`
  3. `ШК короба`
  4. `Срок годности`
  5. `ШК короба для печати в стороннем сервисе`
- Колонки `ШК короба` и `ШК короба для печати в стороннем сервисе` заполняются сохранённой парой того же физического короба; товарные строки строятся из состава ELESTET.
- При отсутствии WB ШК вариант остаётся на месте, но недоступен; рядом показывается краткая причина `Отсутствует`.

Подробная логика импорта, identity и статусы публикации находятся в `memory-bank/components/wb-excel-export.md`. Memory Bank описывает правило, а runtime обеспечивает общий TypeScript helper и профильные библиотеки экспорта.
