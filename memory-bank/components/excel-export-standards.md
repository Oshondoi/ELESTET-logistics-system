# Excel export standards

All Excel files generated by ELESTET must use `applyExcelWorksheetStandards` from
`src/lib/excelStandards.ts` before the workbook is written.

Rules:

- Column width is calculated automatically from the header and cell contents.
- The default maximum width is 60 characters so long descriptions do not make a sheet unusable.
- Product barcodes, WB and seller articles, box barcodes, order IDs and supply IDs are stored as text.
- Quantities, prices and dates remain numeric/date values where the export supports them.
- Honest Mark (`Честный знак`) codes are excluded from automatic conversion until their format is approved separately.
- Fulfillment exports support three modes at batch, supply and individual-box level:
  `По коробам`, `По баркодам`, and `Оба`.
- `Оба` is one XLSX workbook with `По баркодам` as the first worksheet and `По коробам` as the second worksheet.
- `По баркодам` contains one row per product barcode and sums quantities from all included boxes.

The memory bank documents the rule; the application does not read it at runtime. Runtime enforcement is provided by the shared TypeScript helper.
