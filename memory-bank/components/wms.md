# WMS — стеллажи и адресация коробов

## Иерархия

`Склад → Стеллаж (wms_zones) → Паллетоместо → Сторона → K-место → Короб → Товар`

- `B3` — паллетоместо: столбец B, ярус 3.
- `S1/S2` — стабильный внутренний код стороны. Название пользователь может менять без изменения адресных связей.
- `K5` — пятое место короба на выбранной стороне паллетоместа.
- Пользовательский адрес: `Лицевая сторона · B3-K5`.

## Стойки

- `wms_zones.upright_after_cols` содержит порядковые номера столбцов, после которых стоит вертикальная металлическая стойка.
- Стойка визуально проходит через заголовок и все ярусы, но не является местом хранения.
- Режим `interval` рассчитывает границы через `upright_every`; режим `custom` хранит выбранные пользователем границы.

## Стороны и места

- `wms_zone_sides`: `zone_id`, `code`, `name`, `slot_columns`, `slot_rows`, `slot_count`, `position`.
- У стеллажа минимум одна и максимум две стороны. Ограничение проверяется в UI, RPC и DB-trigger.
- По умолчанию: `S1 / Лицевая сторона / 2×4`, `S2 / Задняя сторона / 2×4` — по восемь мест.
- Пользователь может переименовать стороны и настроить ширину/высоту; произведение ограничено 100 местами на сторону.
- Места выводятся визуальной сеткой и нумеруются слева направо, сверху вниз: `K1 K2 / K3 K4 / K5 K6 / K7 K8`.
- Схема действует на все паллетоместа стеллажа.
- В модалке паллетоместа стороны показаны отдельными физическими сетками; пользователь не обязан вычислять номер K по плоскому списку.

## Короба

- Новый физический короб — отдельная строка `wms_cell_items` с `item_type='box'`, `qty=1`, обязательным `barcode`, `side_id`, `slot_number`.
- ШК является источником QR; QR не является отдельным идентификатором.
- Уникальные индексы защищают от двух коробов в одном K-месте и повторного непустого ШК короба внутри компании.
- Legacy-короба остаются без адреса (`side_id/slot_number = null`) и назначаются через UI.
- Внутри открытого паллетоместа первый клик по занятому месту выбирает короб. Следующий клик по свободному месту на любой стороне переносит его, по занятому — меняет два короба местами.
- `move_or_swap_wms_box` выполняет перенос/обмен одной транзакцией. Идентификатор, ШК/QR и содержимое коробов не изменяются.

## Защита изменений

- `save_wms_zone_layout` сохраняет сетку, стойки и стороны одной транзакцией.
- `validate_wms_zone_resize` запрещает обрезать существующие паллетоместа.
- `validate_wms_side_resize` запрещает удалить занятые номера K.
- FK `side_id ... on delete restrict` запрещает удалить используемую сторону.
- `validate_wms_box_slot` проверяет принадлежность стороны стеллажу и диапазон K-места.
- `validate_wms_side_limit` запрещает третью сторону.
